# 赞助二维码 / Sponsor QR Codes

将真实的收款二维码图片放入此目录：

- `sponsor-alipay.png` — 支付宝收款码
- `sponsor-wechat.png` — 微信收款码

替换后 README 中的赞助区会自动显示正确的二维码。
